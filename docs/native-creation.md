# iOS のノート操作と軌跡動画

更新日: 2026-11-01。提供画像の iOS 1.18 と公開説明を基準にする独立実装です。細部までの一致や、実機での確認が完了したという記録ではありません。

## ノート

UIKit のタップ・パン・ピンチ・回転を紙の編集面に接続しました。紙の座標で配置を保存するため、表示幅が変わっても保存座標は変わりません。紙の中心、ほかの素材の端、水平へ近づくと整列を補助します。閾値は独自の値で、本家の数値を復元したものではありません。

スライダーによる位置・大きさ・角度の調整、透明度、手前への移動、40 回までの配置 Undo も使えます。素材の追加データを保ちながら編集し、保存失敗時は下書きを保持します。変更を保存せず閉じる場合は確認します。

選択枠やガイドは編集面だけの描画です。PNG には紙と内容だけを書き出します。共有はノート内の標準共有シートから行い、共有のキャンセル後もノートの編集に戻れます。1 日に複数ページを作る構造や、本家と同じ仕上げ・触感までは未再現です。

## 動画

AVFoundation の AVAssetWriter と CoreGraphics で MP4 を作ります。既定は縦 720 × 1280、24 fps、12 秒です。保存済みの軌跡、配色、線種、実距離と単位をスナップショットにして書き出します。位置の区切りや別のさんぽを線でつなぎません。

プレビュー用に間引いた配列を動画へ流用せず、元の点列から端点を保つ描画用データを作ります。区間や点数・出力サイズを制限し、画像・文字の描画とエンコードは UI の外で処理します。進捗表示とキャンセルに対応し、一時ファイルは専用フォルダだけを片付けます。成功した動画は標準共有シートが受け取るまで保持します。

写真・実地図の透かし・本家と同じ演出・期間を指定する編集は未対応です。基本の線の成長動画であり、公式動画と同じ映像とするものではありません。

## 検証と CI

配置の境界・回転・整列・追加メタデータの保持を純粋な計算で検査します。動画は実 MP4 を生成し、映像トラック・長さ・大きさを読み、フレームを復号します。区切り・日付変更線・多数の短い軌跡・キャンセルも検査します。SDK 実行結果は README の最新 CI リンクを参照してください。

検証の再試行でアプリを再コンパイルしなくて済むよう、CI はビルドと Simulator 実行を分離しました。ビルド済みアプリを tar にし、検証ジョブで展開します。両方を同じ arm64 の `macos-26` に固定しています。利用可能なランナーとアーキテクチャは [GitHub の公式資料](https://docs.github.com/en/actions/reference/runners/github-hosted-runners)を確認しました。

実際の複数指操作、Share/AirDrop の受け渡し、カメラ、背景 GPS、実端末の負荷・電池消費、完全一致の比較は実機で確認する必要があります。
