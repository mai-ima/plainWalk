# iOS のノート操作と軌跡動画

更新日: 2026-11-01。提供画像の iOS 1.18 と公開説明を基準にする独立実装です。細部までの一致や、実機での確認が完了したという記録ではありません。

## 参照した機構

公式の説明・取得済み Web コード・APK の静的な記録構造は [参照元と実装の対応](reference-mechanisms.md)にまとめています。Web デモの仮想歩行と実 GPS、Android の型情報と iOS の操作仕様を分けて扱います。

## ノート

UIKit のタップ・パン・ピンチ・回転を紙の編集面に接続しました。紙の座標で配置を保存するため、表示幅が変わっても保存座標は変わりません。紙の中心、ほかの素材の端、水平へ近づくと整列を補助します。閾値は独自の値で、本家の数値を復元したものではありません。

スライダーによる位置・大きさ・角度の調整、透明度、手前への移動、40 回までの配置 Undo も使えます。素材の追加データを保ちながら編集し、保存失敗時は下書きを保持します。変更を保存せず閉じる場合は確認します。

選択枠やガイドは編集面だけの描画です。PNG には紙と内容だけを書き出します。共有はノート内の標準共有シートから行い、共有のキャンセル後もノートの編集に戻れます。1 日に複数ページを作る構造や、本家と同じ仕上げ・触感までは未再現です。

## 動画

AVFoundation の AVAssetWriter と CoreGraphics で MP4 を作ります。既定は縦 720 × 1280、24 fps、12 秒です。保存済みの軌跡、配色、線種、実距離と単位をスナップショットにして書き出します。位置の区切りや別のさんぽを線でつなぎません。

プレビュー用に間引いた配列を動画へ流用せず、元の点列から端点を保つ描画用データを作ります。区間や点数・出力サイズを制限し、画像・文字の描画とエンコードは UI の外で処理します。進捗表示とキャンセルに対応し、一時ファイルは専用フォルダだけを片付けます。成功した動画は標準共有シートが受け取るまで保持します。

写真・実地図の透かし・本家と同じ演出・期間を指定する編集は未対応です。基本の線の成長動画であり、公式動画と同じ映像とするものではありません。

## 検証と CI

配置の境界・回転・整列・追加メタデータの保持を純粋な計算で検査します。途中で片指を残して再びピンチ・回転を始める場合に、拡大率が元へ戻らない回帰検査も含めます。動画は実 MP4 を生成し、映像トラック・長さ・大きさを読み、フレームを復号します。区切り・日付変更線・多数の短い軌跡・キャンセルも検査します。SDK 実行結果は README の最新 CI リンクを参照してください。

検証の再試行でアプリを再コンパイルしなくて済むよう、CI はビルドと Simulator 実行を分離しました。ビルド済みアプリを tar にし、検証ジョブで展開します。両方を同じ arm64 の `macos-26` に固定しています。利用可能なランナーとアーキテクチャは [GitHub の公式資料](https://docs.github.com/en/actions/reference/runners/github-hosted-runners)を確認しました。

実際の複数指操作、Share/AirDrop の受け渡し、カメラ、背景 GPS、実端末の負荷・電池消費、完全一致の比較は実機で確認する必要があります。

## 今回の実行結果

[CI 41297028999](https://github.com/mai-ima/plainWalk/actions/runs/41297028999) の全 4 ジョブが成功しました。Xcode 本体と拡張、Playgrounds をコンパイルし、Simulator で配置計算・ジェスチャー再開の回帰検査と、実 MP4 の生成・復号・途中キャンセルを実行しました。合成データの試験動画は H.264、360 × 640、8 fps、1 秒です。14 画面の中に空のノート編集画面を含め、診断画像の文字検出も通過しました。複数の指で実際に操作した試験ではありません。

前段の CI では、写真追加画面の完了待ちが一度時間超過しました。同一コードの再試行は成功しています。期限後の PNG で画面は見えましたが、期限内の描画と原因は確定しません。中間の CI 41295495000 では記録、41296423376 では設定の完了待ちが失敗しました。後者のログは、追加した UIKit の移動フラグの条件で停止したことを示しました。その条件を取り除きました。今回は UIKit の親子関係だけに依存せず、選択中の画面を条件にし、背景の表示完了通知を一度だけ待つ方式を補強しました。実描画・window・非ゼロの表示範囲・遷移完了を確認した上で 0.5 秒後も状態が同じなら完了にします。各画面の起動前に古い完了ファイルも削除します。修正後の単回成功は、あらゆる低速環境での安定性を保証するものではありません。


追加の [全画面確認](screen-coverage.md)で、ノートの下部まで撮影するスクロール先を修正しました。[CI 41302732947](https://github.com/mai-ima/plainWalk/actions/runs/41302732947) の全 11 ジョブが成功し、素材のあるノートと、位置・大きさ・傾き・透明度・共有の下部を実画像で確認しました。これは実際の指による編集や AirDrop の試験とは別です。
