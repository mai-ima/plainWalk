# PlainWalk 1.18.0 の画面・操作・機能分析

調査日: 2026-10-29。対象はユーザー提供のアプリ画面と、Apple の Lookup API で確認した iOS 版 **1.18.0**。API の公開日は 2026-10-25。ユーザー画像の設定画面は **1.18.0 (191)** を表示している。

完全な実機操作記録やソースコードを入手したという意味ではない。提供画像で見えている全画面・項目と、公開資料で確認できた機能を整理した。未撮影の画面、内部計算、動画・触覚の細かな時間は未確定。

### 版による不一致

公式トップの更新欄は1.17まで。プライバシー説明は2026-09-30で、ヘルスケアは読み取りのみと記載するが、提供画像の1.18設定には「さんぽをヘルスケアに保存」がある。機能と権限は一つの資料だけで確定させない。iOS 27 向けに限定された機能も1.18の説明に含まれ、iOS 17で動く基本機能とは分ける。

## 2. 全体の画面構造

下部は **マイマップ / 記録 / プロフィール** の3タブ。マイマップのアイコンは折り地図ではなく、大小のきらめき。記録は棒グラフ、プロフィールは人型。

- マイマップからメニュー、答え合わせ、現在地、地図レイヤー、記録操作へ。
- プロフィールからここいいな、ステッカー、エリアバッジ、らくがき、共有の白地図、気になる場所、設定などへ。
- これらのコレクションは全面のページで、左上が丸い戻るボタン。常に下部タブが見える。
- 地図レイヤーは下から出る長いシート。角丸、上部の短いハンドル、中央の題、右の白い「閉じる」ピル。本文をスクロールしても題と閉じるを保つ。
- 設定は全面のグループ化されたリスト。白いグループ、薄い紫寄りの灰色の背景、グループ間の灰色の説明。
- 答え合わせは地図が全面。中央の題、右上の閉じる、右下の地図種と現在地、下に目的地とらくがきのピルが重なる。

## 3. 見た目の規則

### 基準寸法

提供画像は幅588px、縦1280px。iPhone の論理幅約393ptに対応する倍率と推定できるが、端末型番・表示ズームは未確定。画像の1pxをそのままCSSの1pxにしない。

- 左右の主要余白はおよそ16pt。
- 丸い戻る・メニューボタンは約44pt。白に近い面と柔らかな影。
- グループの角丸は約24〜28pt。
- タイトルはSF系の太字で中央。グループ見出しは薄い灰色の中太。
- 本文の行は約50pt、スイッチは標準iOSの緑、区切りは薄いヘアライン。
- 下部タブは約54ptにホームインジケーター側のセーフエリアを足す。以前の実装の76pt＋セーフエリアは大きすぎる。
- 購入制限は廃止する指示により、PLUS・王冠・鍵と購入復元の導線を再現しない。
- OS の時刻・電波・電池は画面内に偽装しない。

### 色

公開アセットの標準＋14配色のpaper/ink値を確認済み。iOSのグループ背景・区切り・無効色はスクリーンショット比較で詰める。現時点では色管理・圧縮・表示環境まで揃えた画素一致ではない。

## 4. マイマップ

### 初期画面

中央は道路も建物名も出さない紙。上中央に短い二行のコピー。左上にメニュー、右上に答え合わせ。左下は歩数、開拓した道、総開拓距離。中央下は足跡の丸ボタンと「軌跡を残す」。右下は現在地と地図レイヤー。初期の参考画像にはカメラの丸ボタンが常時表示されていない。

数字は大きな太字、単位は小さい。歩数の値は端末由来で、画像の6,144を固定データとして埋め込むことはしない。

### 状態

1. 記録なし・位置未取得。
2. 位置取得済み・新しい紙。
3. 記録中: 新しい線と他の線を区別。
4. 一時停止: 空白期間を直線でつながない。
5. 長押し終了: 保存と達成表示。
6. 旗あり: 方角と直線距離。道路に沿ったナビではない。
7. 自動検知が権限不足: 灰色の背景と中央の角丸警告。「あとで」と設定を開く操作。

画像の警告は位置権限が「常に」でなくなった状態。これをWebで偽装表示しない。ネイティブの実際の許可状態で判定する必要がある。

## 5. 地図レイヤー（画像の順番）

| 順序 | 項目 | 観察した仕様 |
|---|---|---|
| 1 | 配色 | 横に並ぶ丸い選択肢、下に名前。選択中は黒い輪。標準は白地図 |
| 2 | 線 | 実線と点線。丸の中に曲線の見本 |
| 3 | 写真ピン | バッジ、丸、正方形、輪郭、点 |
| 4 | 現在地 | 点、黒猫、茶トラ、三毛、サバトラ。ほかの選択肢の存在は別資料にあり |
| 5 | 地図の輪郭を表示 | 行の右にスイッチ。境界と海岸線、引いたときは広域の輪郭 |
| 6 | 記録中は他の軌跡を薄くする | 新しい線を見やすくする |
| 7 | 移動手段 | 徒歩、ランニング、自転車、乗り物。青いアイコンと個別スイッチ |
| 8 | よく通る道を太く表示 | 訪問頻度を線幅に反映 |
| 9 | 軌跡を整える | 表示の安定化。内部の補正アルゴリズムは不明 |
| 10 | 方眼グリッドを表示 | 初期画像ではオフ |
| 11 | 現在地のハイライト | 青い半透明の円 |
| 12 | 写真を表示 | 写真ピンの表示制御 |
| 13 | つぶやきを表示 | 写真とは別の文字ピンの表示制御 |

移動手段のスイッチは表示だけを変え、歩行距離・開拓距離を変えないという説明がある。生の軌跡を消す実装にしてはいけない。

猫は移動と停止で歩く／座る、端末の向きを向く。大きく引くと点に戻る。画像だけでは3Dモデル、歩行周期、しっぽの振幅を確定できない。

## 6. コレクションの空状態

### ここいいな

白い全面。中央より少し上の大きなカメラ線画、その下に太字の空状態、その下に灰色の一行説明。空のまま大きな投稿フォームを出さない。

写真と動画のある状態、カテゴリ棚、詳細、撮影情報、シェア、撮影時刻と座標の関連を別状態として検証する。

### ステッカー

上に「近くの人と交換・あげる」の白い枠付き行。黒い丸の交換アイコン、太字題、二行の説明、右矢印。下は写真からの切り抜きステッカーが集まる説明。

### エリアバッジ

白い全面。折り地図の大きい線画と空状態。コレクション後は実際の市区町村の形。公式記事では500m区画による塗りが確認できるため、訪れた瞬間に街全体を塗る実装は異なる。

### らくがき

上部のカードに説明と黒いピルの作成ボタン。答え合わせ上で一本指で描き、後で実際に歩いてたどる。

### 共有の白地図

グループ背景。空状態カード、別の白い作成行、灰色の説明。自分が選んだ線だけが外に出る。共有の仕組み・招待URL・サーバー仕様は非公開なので、ローカルファイル交換を同一のリアルタイム共有だとは扱わない。

### 気になる場所

白い説明カード。答え合わせで探した場所をしおりで保存し、必要になったら旗の目的地にする。旗と同一の保存物ではない。

## 7. 設定（画像で確認できる全項目）

### 動き出したとき

三択: 何もしない／知らせる／自動で記録する。選択中の青いチェック。権限不足のときは一時停止中の理由とiOS設定へのリンク。Webの通常のページからバックグラウンド移動を検知することはできない。

### 自宅・職場・よく行く場所

- 登録した場所から記録: スイッチ。
- 自宅、職場、場所を追加: アイコン付き行。
- 未設定の値と右矢印。
- 滞在した場所から記録: 別のスイッチ。説明には一定時間の滞在から出発を検知するとある。
- 場所は地図に出さず、端末内だけで保持する設計。

### 表示・単位

外観の選択、ライト／ダーク／端末に合わせる。単位の選択、地域／km／マイル。距離だけでなく面積・速度・ウィジェット・Watchにも適用する必要がある。

### 歩数・カメラ

1日の目標の行、目標がない状態。LUTの行。歩数は記録中だけでなくその日の合計。1.18の説明には7日グラフと達成演出もある。

### 通知

朝の通知、時刻、週間ふりかえり、さんぽが途切れたら知らせる。参考値7:45は設定例であり、固定のOS通知を勝手に作成しない。通知は利用者が有効にした後で権限を求める。

### Apple ヘルスケア

利用スイッチ、選んだワークアウトを描く、自動で白地図に連携、さんぽをヘルスケアに保存。データがない／権限がない／経路がないワークアウトを区別できる範囲はHealthKit側の制約に従う。

### 入出力・バックアップ・アプリ情報

GPX/TCXから取り込み、すべてのさんぽをGPXに出力、iCloudバックアップ、バージョン、評価、GPS報告、購入復元、データリセット。課金廃止に伴い購入復元は不要。アプリ評価は公式アプリの評価を誘導する偽装にならないよう分ける。リセットは明確な確認とバックアップ導線が必要。

## 8. 答え合わせ

Appleの標準地図を背景に、白地図と同じ位置の軌跡を重ねる。右下のレイヤーで航空写真、3D。右下の現在地。下部の目的地とらくがき。1.18では線をタップして一本を強調、長押しでそのさんぽを開くことが説明されている。

Webで別の地図プロバイダーを使う場合、地名・道路の配色・建物の姿まで一致するとは言えない。提供画像の実座標やユーザーの位置をデモの固定初期位置として埋め込まない。

## 9. 1.18で追加照合が必要な状態

1. 期間を選んだ再生。
2. さんぽ詳細の右上メニュー（命名、GPX、削除）。
3. 写真の白フレーム、比率、撮影情報。
4. 対応カメラのポートレート深度とぼけ。
5. 既存写真を軌跡の地点に配置し、時刻を合わせる操作。
6. ノートのスナップ、ズーム、透明度、テープ・手書き変形。
7. ステッカーの塗り足し・消去と拡大鏡。
8. モーション種別別の距離と週間・日付別の統計。
9. 歩数目標の進捗・達成と、任意通知。

これらは公開の説明で存在を確認した段階。画面の実物がない項目は、推測した見た目を完全再現として採用しない。

## 10. データ設計上の区別

- GPSサンプル: 時刻、座標、精度、区切り、可能なら移動種別。
- さんぽ: 複数の連続セグメント、名前、開始終了、手直し履歴。
- 開拓: 道を重複加算しない指標。原データと表示の補正を分離。
- ここいいな: 写真／短動画／つぶやき、位置・時刻・カテゴリ。
- ステッカー: 写真の被写体と透明マスク、仕上げ。
- バッジ: 実境界と500mの訪問区画。
- 気になる場所: 将来の目的地。記録した経路や現在の旗と分離。
- らくがき: 未踏の目標の線。歩いた実績として加算しない。
- 共有: 利用者が選択して送った線だけ。未送信の写真や自宅を含めない。
- 権限と設定: OSの実際の状態を表示し、見た目だけのスイッチを作らない。

## 11. この移植での優先順位

1. 提供画像と異なっていたタブ、余白、画面種別、スイッチ、レイヤーの選択UIを合わせる。
2. クリックできるだけの画面ではなく、保存・復旧・戻る・空状態まで成立させる。
3. WebKitでタッチ・Canvas・入力・保存を検証し、iPhone実機との差を残す。
4. 日本の実境界判定から、表示範囲の輪郭と500mのバッジ塗りへ進める。
5. ネイティブに必要なOS機能は別ターゲットで接続し、Xcode未検証を明記する。
6. 作業の区切りでGitHubへコミットを追加し、Vercelはユーザーの手動取込に対応する。

## 12. 未確定・未入手

公式アプリの全画面遷移、全エラー、全OS・全端末、正確な触覚とアニメーション時間、猫モデル、補正・活動判定の内部コード、共有プロトコル、正確な境界配布セット、すべての通知の抑制条件、全カメラの深度挙動。これらを確認済みとは記載しない。

## 最新の実装追記

参考画像のステッカー・らくがき・共有白地図・気になる場所のページを追加。ステッカーはノート素材の一覧と PNG 共有、らくがきは地図上の描画・保存・歩行時の点消去、しおりは保存から目的地の旗への接続。共有は日時・メモ・写真を除く線の JSON ファイル方式で、公式の招待リンク・自動同期とは異なる。iOS Simulator 起動・Web/native 接続・位置ジャーナル復旧は Actions 40888890524 で通過。
