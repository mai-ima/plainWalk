# 公式 Web・APK と実装の対応

確認日: 2026-11-01。公開説明、配信済みの Web JavaScript、Android の静的メタデータを、別の根拠として扱います。公式サーバーのソースや iOS アプリの全ソースを取得したものではありません。

## 公式サイトの Web コード

[公式サイト](https://plainwalk.app/)の本文を再確認しました。以前取得した HTML は `assets/main-CIQm0wIm.js`、`assets/svg-C2EGAaNn.js`、言語・ランタイム用のスクリプトを参照しています。今回再読した main バンドルは 612,644 bytes、SHA-256 は `477e1a0cb6411b0648ebdd9ee7eb659ccf52869ebba3dda2274c2307ae265b08` です。これは取得済みの資料の識別値で、現在配信されるファイルとの一致を再検証した値ではありません。

バンドルには Three.js の描画処理に加えて、次のサイト用の動作があります。コードの転載はせず、観察事項だけを記録します。

| 確認した動作 | 参考にする点 | 推定しないこと |
|---|---|---|
| スクロール位置から場面を進め、Canvas の 3D 表示・写真カード・バッジを更新する | 余白を保ち、線から写真・収集へ見せる順序 | サイトの演出時間が iOS のアニメーション時間と同じであること |
| タップ地点をデモ内の道路網へ対応させ、仮想の歩行者を動かす | 白地図に線が増える体験、記録ボタンの状態表示 | 実 GPS の測位・精度判定・歩数計測の実装 |
| 道の訪問状態を表示用の距離・歩数へ変換する | 再訪と新しい道を見分ける情報の構成 | デモの換算式を実端末の歩数や開拓距離に使うこと |
| 配色の選択を紙・線・3D 表示へ反映する | 設定と描画の一貫性 | Android / iOS の全配色・暗色の内部定義との一致 |
| ポインター位置に応じたカードの傾きと、動きを減らす設定への対応 | 操作に応じた反応とアクセシビリティ | 本家のジャイロによる素材仕上げが再現済みであること |

このリポジトリの Web 正本は `web/` です。公式の販促デモのバンドルを組み込まず、ブラウザの位置情報、記録状態、IndexedDB、描画・出力を独立実装しています。Swift は同じ保存契約を参考にしつつ Core Location・SwiftUI・MapKit・AVFoundation で構成しています。

## APK から参考にした仕組み

対象は Android 1.1.0 の取得済み base APK です。ハッシュと解析範囲は [APK の記録機構](apk-mechanism-notes.md)に残しています。

位置入力、センサー、動作イベント、記録セッション、保存データが分かれている構造を、独立版の記録・復旧・描画・GPX 出力の整合性の照合に使います。`leg` は整数、`edited` は Boolean であり、後者を位置欠損とは読み替えません。独立版の `gap` / `isBreak` とは別形式です。静的な API 参照だけでは、精度や速度の閾値・保存の原子性・背景動作の保証を確定できません。

## 今回のネイティブ機能への適用

[公式の旅行記事](https://note.com/plainwalk/n/nf160cabe8248)で、写真・ステッカー・道を紙へ置くノートと、歩いた順に線が伸びる動画を再確認しました。[公式の開拓記事](https://note.com/plainwalk/n/na2b6feb9eade)には、動画の最後に実地図を重ねる説明もあります。

この範囲をもとに、Swift のノートへ直接の移動・拡縮・回転を、再生へ実 MP4 出力を追加しました。元の記録を変更せず、保存した実距離・単位・点列の区切りを出力へ保持します。複数ページのノート、動画への写真・短動画の挿入、実地図の透かし、本家と同じ素材仕上げは残差です。[実装と検証](native-creation.md)に、確認済みの計算・SDK・Simulator と、未確認の実機操作を分けています。


## 2026-11-10 の追加照合

[旧Androidの開拓距離の追加解析](android-grid-research-2026-11-10.md)で、保存原点・12mセル・約2m中点サンプルの按分・記録境界での状態リセット・距離入力の定数を確認しました。24メソッドの位置とハッシュ、8つの独立計算例を残しています。現行iOSの式が同じだと確認したものではありません。

現在の独立近似には、記録分割の残差に加え、同じ道の過去記録を追加すると合計が減る再現例があります。簡略な修正試作にも挿入順序の反例が残り、採用していません。今回の変更は分析記録だけで、アプリ・IPA・保存済み記録の既定値は変更していません。完全一致の認定には、現行iOSの同条件での全画面・操作と、署名済み実機での比較が不足しています。
