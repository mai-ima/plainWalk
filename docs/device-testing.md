# 実機での開発者機能

## 開く

プロフィール → 設定 → 開発者モードをオンにする。

- Web: 「実機検証・診断ログ」を開く。
- iOS / Playgrounds: 設定と実機検証は SwiftUI の画面を開く。通常の Xcode 版と Playgrounds 版の機能範囲を区別する。

## 使える確認

- 権限の状態、位置精度、最終測位からの時間、記録点数、OS と実行環境。
- 保存の往復テスト。専用のキー / 一時フォルダで書いて読み、内容を照合して削除する。実際の記録・設定の保存先は上書きしない。
- DEBUG の Swift 版では、隔離した位置ジャーナルの復元と重複排除を確認する。
- Web の描画テストは requestAnimationFrame の間隔を測る。GPU 性能や実際の操作全体の FPS を保証する値ではない。
- Web のタップ領域の枠、GPS 状態 HUD、手動で記録する確認結果。
- Web の診断ログは最大 250 件、SwiftUI の診断画面のイベントは最大 100 件。座標・軌跡・写真・場所名・メモを入れず、JSON は自分で共有を押したときだけ書き出す。

画面を開くだけでは位置情報・カメラ・マイクの許可を新しく要求しない。モードをオフにすると Web の HUD と枠を外し、ログを消去する。チェックリストは実機で確認した結果を自分で選び、自動で合格にはしない。

## iPhone の確認手順

1. Xcode 版を実機に署名・インストールし、位置情報を許可して歩き始める。
2. 一時停止と再開を確認し、診断の点数と状態が変わることを確かめる。
3. 画面をロックして 15 分以上歩き、復帰後に軌跡・距離・点数を比較する。
4. 位置の拒否・概算位置・権限取消、通信の切断、端末の低電力状態を試す。
5. さんぽを保存し、アプリ終了・再起動後に同じ記録があることを確認する。
6. バックアップを書き出して取り込み、重複や欠落がないことを確認する。
7. VoiceOver、文字サイズ、縦横画面、ダークモード、共有シートを確認する。

Playgrounds 版は前面 GPS のみを対象にする。HealthKit・Live Activity 拡張・ロック中の継続記録の検証には通常の Xcode 版を使う。

CI でのコンパイル・Simulator 起動と、この実機検証を同じものとして扱わない。SwiftUI 設定画面の Simulator 起動画像も CI のアーティファクトに保存する構成。

スリープ防止は beta の設定を有効にした記録中だけ働きます。Xcode / Playgrounds 版は UIApplication の idle timer、Web は対応ブラウザの Screen Wake Lock を使い、記録の停止・一時停止で解除します。
