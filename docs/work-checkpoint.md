1. このチェックポイントの `Verify web and iOS` を確認し、失敗があれば該当ジョブのログから修正。特にMapKitカメラの実状態・日付変更線・新しいNativeモデル自己テストを確認。
2. 新コミットの86枚を取得・OCR照合し、3Dに街区と軌跡が出ること、タブ・レイヤー・写真一覧の余白を画像で確認。日本語localeを明示して撮影する設定を追加済み。
3. Web114枚を再撮影。3Dは未対応の説明として扱い、偽の傾斜画像を対応済みにしない。
